Record only; not in 202.
- **B5F-005 — Governed script refusals can name the wrong cause when a path does not resolve (deferred; 2026-10-13, feature 202 code-implementation lens):** under the 202 principle, the system diagnoses its own failures. Evidence: specs/202-beta4-1-ux-stabilization/workshop/intake-drift-log.md DRIFT-202-INTAKE-008. Record only; not in 202.

- **B5F-018 — A running round shows no progress (named backlog; 2026-11-01, 203 T002 rounds 1 to 3):** for about 30 minutes the human sees only "requested" and "reserved" (in a background launch, nothing else), then heartbeats that say activity is not progress. Nothing says which step is running (the pre-review checks, the reviewer, the harvest), which verification lane is running, or how long is left. The engine records no per-lane duration either, so the crew cannot answer "status?" beyond the elapsed time. The reviewer's findings file is written inside the temporary review copy and stays invisible until harvest. A round should report its step, its current lane with that lane's measured duration, and an estimate of what is left, and write that where the crew and the human can read it while the round runs. Progress shown to the human uses the human's local time, not UTC. Pairs with B5F-016. Maintainer's ruling.

The pin script leaves the package. Maintainer's ruling. **Added after 203 T002 review rounds 4 to 7 (2026-11-02):** the per-machine launcher's root discovery now stops at a pin record (`03dd3c3b`), and a missing pin helper refuses in every provider (`c988b849`). Round 7 found the remaining class: a file missing from inside the pin makes a hook-path load fall back to the project's copy. Two sites are named: the SessionStart refocus lookup of `work-kind-common.ps1` and `Get-DispatcherCatalog`'s fallback to the source `refocus-scopes.json`. Acceptance: a sweep of every hook-path load in which, with a pin record, a missing pinned file refuses visibly and never loads the project's copy, each site covered by a project-side trap; or the target design above, which removes the fallbacks.
