Example observed this session: the material-work turn-end declaration force-continues a stop that carries no human decision. Record only; not in 202.
- **B5F-005 — Governed script refusals can name the wrong cause when a path does not resolve (deferred; 2026-10-13, feature 202 code-implementation lens):** under the 202 principle, the system diagnoses its own failures. In fact the agenda was confirmed, and the plan file simply was not found at the resolved path. A refusal like that sends the agent, or the human, to repeat work that is already done. Refusals should state what was looked for and where (the resolved path) before concluding that something is absent.
