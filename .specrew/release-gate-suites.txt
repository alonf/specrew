# Release-cadence test suites (maintainer ruling, 2026-08-26).
#
# Every file here is EXECUTED by the release gate before any tag or package, and is NOT part of
# the per-round verification lanes. That split is a cost decision, not an accident: the lanes stay
# fast so every round can afford them, and the whole tree runs where slowness is affordable.
#
# This list exists so the choice is READABLE. A suite that appears in no lane and not here fails
# the membership guard immediately (tests/unit/every-suite-is-named-by-a-lane.tests.ps1), which is
# what stops a new suite being written into silence - the cause of DRIFT-199-I001-134, where 331
# suites ran in no lane and twelve of them were red for days.
#
# To move a suite to per-round cadence: name it in a command in .specrew/verification-plan.json and
# delete its line here. To retire a suite: delete the file and its line together.
